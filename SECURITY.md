# Security reports

Please do not report vulnerabilities, credentials or private note content in public issues.

Use **Security → Report a vulnerability** on this repository to make a private report. Include the affected version, expected/observed behavior and a reproduction using synthetic data. Do not include API keys, authentication files or real note contents.

If you believe a credential has been exposed, revoke or rotate it with its issuer. Deleting a public post or Git commit is not sufficient to invalidate a credential.

This project is a desktop beta. Only macOS has been verified so far; read [PRIVACY.md](PRIVACY.md) before connecting your model provider.
