# 页间 Folio · Obsidian 桌面试用版 0.3.5

在 Markdown 笔记选中文字，留言修改或提问；也支持 HTML 点选批注。沿用本机 Codex 配置。

## 安装

1. 解压 `folio-codex-0.3.5.zip`，将整个 `folio-codex` 目录放入你的笔记库 `.obsidian/plugins/`。
2. 在 Obsidian「设置 → 社区插件」允许社区插件并启用 **Folio Codex · 页间**。如未显示，重启 Obsidian。
3. 运行命令 **Folio 页间：创建 HTML 示例并开始批注**，或右键库内 HTML 选择「用页间打开并批注」。文件列表中看不到 HTML 时，在 Obsidian「文件与链接」开启「显示所有类型文件」，也可通过页间左侧文档列表选择。
4. 点击标题，留言“字号改为 30px，颜色改成深绿色”，执行、查看效果，再采用、保存。

插件无需启动网页服务。需要先安装并配置可正常使用的 Codex CLI。插件设置支持可执行文件路径和独立 CODEX_HOME；使用环境变量认证的人应从具有这些变量的环境启动 Obsidian。当前不支持 Codex 默认 profile。

## Markdown 原地批注（0.3.2）

1. 正在看笔记时，点击左侧唯一的「页间：批注当前文档」，直接在当前笔记启用点选，无需再选文件。侧栏打开后会自动跟随当前文档；阅读视图可以直接点选，编辑视图保留编辑状态，可通过右键对选中文字提问。
2. 鼠标移到正文时显示虚线范围；点击段落后，绿色边框标明所选范围，旁边出现「修改 / 提问」。
3. 点击「提问 / 修改」，在段落旁弹出的输入框写留言，点击发送，或按 ⌘ / Ctrl + Enter。提交后，段落右下方立即留下问题卡片，点击展开看回答。
4. 修改卡片点击「审阅修改」，在侧栏查看对比，再点击「采用并保存」。问答详情中的引用可回到正文高亮。
5. Esc 先收起输入框并保留草稿，再按一次退出点选。关闭面板或重开笔记后，阅读视图仍显示已保存卡片。

段落、标题、列表、表格和 callout 按 Obsidian 渲染段落对应源码行定位。整张表或整个列表是一个范围；若只改几个字，仍可在编辑模式选中文字，右键「页间：修改 / 提问」。文件标题、属性面板和其他笔记的嵌入内容不参与正文点选。图框和工具条不会写入笔记。

留言、建议和回答保存在插件 `state.json` 的 `notes` 字段，每篇保留最近 30 条；保存前备份位于 `note-history/`。卡片不写入 Markdown，生成失败时问题仍保留。关面板会停止生成。上下文只包含选区和当前笔记（较长笔记为附近约 24 KB），不会自动读取链接笔记或联网检索。卡片和引用对应当时完整笔记版本；笔记任何位置改变后，旧留言保留在侧栏历史，不再挂到正文，需重新选择并提问。每篇笔记最多 5 MB，每次选区最多 20 KB。

第一版每条留言独立生成，不自动将历史回答作为后续提问上下文。Word/PDF 尚未接入。

回答支持 Markdown 标题、加粗、列表、引用、表格和代码块；段落卡片与右侧详情使用相同排版，历史回答无需重新生成。复制回答保留原始 Markdown。回答中的 HTML、可执行代码块和内嵌图片不执行或自动加载。

切换笔记会保存各自的输入草稿；如果上一篇正在生成，先停止生成并保留记录，再跟随新笔记。关闭侧栏后不会自动重开。没有打开笔记、打开 Excalidraw 画布或其他不支持的文档时会说明原因，不使用上一个笔记的上下文。需要查找其他笔记时，可使用独立命令「浏览其他 Markdown 笔记」。

## HTML 文件与草稿

- 保存会更新选中的库内 HTML；导入或「另存 HTML」在库内 `Folio/` 新建副本，不覆盖同名文件。
- 采用修改后先自动暂存，再由你点击保存。留言、自动草稿与保存前备份在插件目录的 `state.json`、`state.previous.json` 和 `history/`，删除插件目录前请先保存或导出。
- 多窗口的未保存草稿分别保留。原文件有更新时拒绝覆盖，可将冲突草稿另存为新文档。
- HTML 移动/改名后请先保存或导出旧视图的草稿，再重新打开；当前按路径识别文档。
- 不会扫描全部笔记发给模型。执行时发送所选元素源码、相关样式及留言，由你的 Codex 配置决定模型服务与费用。

## 当前范围

桌面端、受控单文件 HTML（导入文件不超过 25 MB，提取图片后的正文不超过 5 MB）；支持实际元素点选，不要求预先划分模块。外部 CSS、SVG、CSS 背景图、脚本、任意网站、Word/PDF 暂不支持。Markdown 使用 Obsidian 原生编辑器，支持选中文字或光标段落留言。首次仅验证 macOS，Windows/Linux 尚未验证。此包是本地试用插件，尚未上架社区市场。

插件自己的 JavaScript 依赖已打包。安装 Codex 所需的运行环境取决于你使用的 Codex 安装方式。

## 网页缓存打不开时

文档列表默认只显示可直接编辑的 HTML，可按文件名或目录搜索。勾选「显示需转换文件」，选择网页后点击「创建静态副本并打开」。副本放在 `Folio/`，原网页不改动。转换会复制支持的图片，并移除脚本、嵌入内容和外部样式；脚本生成的内容或外链样式不会保留。

## 选择或导入

左侧统一为一个页间图标：看 Markdown 时批注当前笔记，看 HTML 时打开对应工作台；已在工作台时直接复用，不重复打开或刷新。没有当前文档时显示选择首页，可打开 Markdown 笔记、选择库内 HTML 或导入 HTML。导入在笔记库 Folio 目录创建副本。需要从当前笔记转到导入入口时，运行命令「打开文档选择与 HTML 导入」。

## 本地链接

支持导入含相对路径、绝对文件路径及 `file://` 链接的 HTML，源码中的链接会保留。批注预览不会跳转或加载链接指向的文件。关联的本地图片和 HTTP(S) 图片会在导入时复制到笔记库；外部 CSS 和脚本不加载；含不兼容内容的导入文件可选择创建静态副本。

## 图片导入（0.2.5）

从「导入 HTML 文件」选择原文件时，支持 `<img src>` 的相对路径、绝对路径、`file://` 和 HTTP(S) 图片。原图复制到 `Folio/attachments/` 并按内容去重，HTML 保存相对路径；移动到其他电脑时请一起带上附件目录。单张最多 8 MB，每份最多 32 张引用图片、预览图片总量最多 32 MB，网络下载总期限 20 秒。不支持 SVG、srcset、CSS 背景图或需登录的图片服务。

缺图时不创建残缺 HTML，提示具体缺失路径；请把 HTML 与原有 assets 目录放在一起再导入。库内现有 HTML 可以读取库内图片；库外图片需通过导入复制。原图被旧版静态转换移除的副本，需要重新导入原 HTML。预览仍使用隔离 data: 图片，HTML 中的脚本不会执行；AI 不可新增未经导入的图片地址。

## 大文件与内嵌图片（0.2.5）

导入 HTML 上限为 25 MB。内嵌 PNG/JPEG/GIF/WebP 图片及大图链接先提取到附件目录，相同图片只存一份，再检查 5 MB 正文上限。原文件、样式和大图链接会保留；无需因为图片内嵌导致文件变大而转换为静态副本。单图仍最多 8 MB。正文或文件超过上限时直接提示，不再建议通过静态转换解决体积问题。
